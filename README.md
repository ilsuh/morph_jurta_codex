# Словоформы русского языка

Статический сайт для поиска начальных форм и словоформ по данным [nlp-rus-zaliz](https://github.com/jurta/nlp-rus-zaliz). Словарь и обратный индекс загружаются по частям. Ударения и словарные пометы сохраняются; предположительные, затруднительные и отсутствующие формы отображаются отдельно.

## Запуск

Для запуска нужен любой HTTP-сервер, например:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`. Нужен современный браузер с поддержкой `DecompressionStream`.

## Обновление данных

Подготовленные данные находятся в `dist/data`. Для повторной сборки требуется Python 3 и PyYAML с LibYAML. Загрузите `zaliz_1.yml` и `zaliz_2.yml` из репозитория источника и выполните:

```sh
python3 scripts/build_dictionary.py /path/to/zaliz_1.yml /path/to/zaliz_2.yml
```

В комплекте использована версия источника `5235199c09ab9e4443aeb7dd0b4d1be299cf80e8`; исходные файлы и описание их формата: <https://github.com/jurta/nlp-rus-zaliz>. Исходный репозиторий содержит лицензию GNU GPL v3; её текст приведён в `COPYING`. Данные словаря и их происхождение описаны в README источника.

Поиск игнорирует регистр, ударение и различие е/ё. Статьи без раскрытой парадигмы отображаются с соответствующим сообщением. Формы с пометкой отсутствия показаны отдельно и не включаются в обратный индекс поиска.

## GitHub Pages

При отправке изменений в ветку `main` workflow `.github/workflows/pages.yml` публикует каталог `dist` через GitHub Actions. В настройках Pages источником должен быть выбран **GitHub Actions**.
